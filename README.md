# 📊 Customer Shopping Behavior Analysis

## 🔍 Overview
This project analyzes customer shopping behavior using transactional data to uncover insights into spending patterns, customer segments, and product preferences. The objective is to support data-driven business decisions through end-to-end data analysis.



## 📁 Dataset
- Total Records: 3,900  
- Total Columns: 18  
- Key Features:
  - Customer demographics (Age, Gender, Location, Subscription Status)
  - Purchase details (Item, Category, Amount, Season, Size, Color)
  - Behavioral data (Discount usage, Frequency, Ratings, Shipping type)
- Data Quality: Missing values handled (e.g., review ratings)



## 🛠️ Tools & Technologies
- Python (Pandas, NumPy, Matplotlib/Seaborn) – Data cleaning & EDA  
- MySQL – Data querying & business analysis  
- Power BI – Dashboard & data visualization  
- Gamma – Presentation creation  



## ⚙️ Project Workflow

### 1. Data Loading & Cleaning (Python)
- Loaded dataset using Pandas  
- Handled missing values using median imputation  
- Standardized column names  
- Created new features (age groups, purchase frequency)  
- Removed redundant columns  

### 2. Exploratory Data Analysis (EDA)
- Performed summary statistics  
- Analyzed distributions and trends  
- Identified key patterns in customer behavior  

### 3. SQL Analysis (MySQL)
- Revenue by gender  
- High-spending discount users  
- Top-rated products  
- Shipping type comparison  
- Subscriber vs non-subscriber analysis  
- Customer segmentation (New, Returning, Loyal)  

### 4. Dashboard Creation (Power BI)
- Built an interactive dashboard with:
  - Total customers  
  - Average purchase amount  
  - Average rating  
- Visuals include:
  - Revenue by category  
  - Sales by age group  
  - Subscription insights  

### 5. Reporting & Presentation
- Created a detailed analytical report  
- Designed a presentation using Gamma  



## 📊 Dashboard Highlights
- Customer segmentation insights  
- Revenue trends by category and age group  
- Subscription behavior analysis  
- Sales performance comparison  



## 📈 Key Results & Insights
- Majority of customers fall under the loyal segment
- Discount usage influences purchasing behavior  
- Certain product categories generate higher revenue  
- Subscription does not always lead to higher spending  
- Spending patterns vary across age groups  



## 📌 Conclusion

This project demonstrates a complete data analytics workflow—from data cleaning and exploration to SQL-based analysis and dashboard visualization. It showcases practical skills in Python, SQL, and Power BI relevant for data analyst roles.
